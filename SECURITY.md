# Security policy

## Supported versions

Security fixes go into the latest release only. Upgrade to the newest
version before reporting, in case the problem is already fixed.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/abhisheksinha1506/lightsout/security/advisories/new),
or by email to abhisheksinha1506@gmail.com.

Include what you found, how to reproduce it, and the lightsout version and
operating system. You can expect a first reply within a week. Once a fix is
released, the advisory is published and you are credited unless you prefer
not to be.

## Verifying releases

Every release file has build provenance recorded by GitHub Actions, and the
checksums file is signed with cosign. See "Releasing" in the
[README](README.md#releasing) for how to verify a download.
