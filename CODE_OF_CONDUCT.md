# Code of Conduct

lightsout follows the
[Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

It applies to everyone taking part in the project: in issues, pull requests,
discussions and reviews, and anywhere someone is representing the project.

## Reporting

If you experience or witness behavior that breaks this code of conduct, report
it to the maintainer at
[abhisheksinha1506@gmail.com](mailto:abhisheksinha1506@gmail.com).

Every report is reviewed and answered. The reporter's identity is kept
confidential.

## Enforcement

The maintainer decides how to respond to a report, following the Contributor
Covenant. Responses can range from a private conversation to removing
contributions or banning someone from the project, temporarily or permanently.
