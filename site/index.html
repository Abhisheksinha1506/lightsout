Lights out.

One command asks every open app to quit, the polite way, and keeps the terminal you're in. macOS, Linux and Windows.

$ brew install abhisheksinha1506/tap/lightsout

Windows: Scoop or a download · Linux: .deb, .rpm or Homebrew · Free and MIT-licensed

$ lightsout

The end of the day, in one keystroke.

Fifteen apps open, three of them hiding unsaved work. Closing them one by one is tedious; force-quit scripts are dangerous. lightsout does it the way you would, just all at once.

It asks. It never forces.

Every app gets the same request as Cmd+Q or its close button. If one wants you to save, it asks you, and lightsout leaves it alone.

  • Apps still open after the timeout are listed at the end, never killed
  • Exits with status 1 when anything is left, so scripts can tell

Knows which window you're in.

lightsout follows its own parent processes, from your shell up to the terminal or editor that started it, and keeps that app open without asking. Terminal, iTerm2, VS Code, Windows Terminal: it works it out.

  • Over SSH or inside tmux it can't tell, so it asks you instead
  • Type 0 when that app is already kept open

Look before you leap.

--dry-run lists exactly what would be asked to quit, and quits nothing. Run it the first time, or any time you're not sure.

Keep what you always keep.

Music playing, a browser full of tabs: tell lightsout once and it never touches them again. Or keep an app for just one run by naming it.

  • lightsout keep and unkeep edit your config for you
  • lightsout Slack "Google Chrome" keeps them this time only

Put it on a schedule.

With --yes, lightsout never stops to ask. If it can't tell which app it's running from, it refuses and quits nothing, so a 7 pm cron job can't close the wrong thing. --timeout gives slow apps longer.

Same command on every desk.

Each platform is asked in its own native way, and each is tested end to end in CI on every change: TextEdit on macOS, an xterm on Linux, Notepad on Windows.

  • macOS: Dock apps by process ID, then Finder windows
  • Linux: app windows through wmctrl on X11
  • Windows: taskbar apps through WM_CLOSE, then File Explorer

Feels at home in your shell.

Tab completion for bash, zsh, fish and PowerShell, and a proper man page. Homebrew and the Linux packages install both; elsewhere one line sets it up.

Signed, and you can check.

Every release records where it was built, and the checksums are signed with cosign by the release workflow itself. Open source, with SBOMs for every download.

  • Build provenance: gh attestation verify
  • Signature: cosign verify-blob on the checksums
  • Scanned by CodeQL, govulncheck and OpenSSF Scorecard

Install in a minute.

One small binary, no runtime. On Linux it uses wmctrl and xprop, which the packages install for you.

Then try lightsout --dry-run first. It quits nothing.

$ brew install abhisheksinha1506/tap/lightsout

macOS and Linux. Installs the man page and shell completions.

> scoop bucket add abhisheksinha1506 https://github.com/abhisheksinha1506/scoop-bucket
> scoop install abhisheksinha1506/lightsout

Windows on x64 or ARM. Or download the .zip from Releases. A winget package is in review.

$ sudo apt install ./lightsout_*_linux_amd64.deb
$ sudo dnf install ./lightsout_*_linux_amd64.rpm

Download the package for your architecture from Releases first (amd64, arm64, armv6, armv7).

$ go install github.com/abhisheksinha1506/lightsout@latest

Any OS with Go 1.26 or newer. Builds from source.

Questions.

Will I lose unsaved work?

No. lightsout sends the same request as choosing Quit or clicking the close button, so apps can ask you to save. Anything still open after the timeout is left running and listed at the end. Nothing is ever force quit.

Which apps does it close?

On macOS, the apps in your Dock (menu bar helpers and system processes are left alone). On Linux, apps with open windows. On Windows, apps on the taskbar. The app you run it from, and any apps you keep, stay open.

Why does macOS ask whether my terminal may control Finder?

lightsout closes Finder's windows with AppleScript, which macOS asks you to allow once. Quitting other apps needs no permission.

Does it work on Wayland?

Only for apps running through XWayland. Native Wayland apps can't be listed by another program, and lightsout warns you in a Wayland session.

Windows says “Windows protected your PC”.

lightsout isn't code-signed for Windows yet, so SmartScreen warns the first time. Choose More info, then Run anyway. Every release has signed checksums and build provenance you can verify.

Is it free?

Yes. lightsout is open source under the MIT license, and bug reports and pull requests are welcome on GitHub.
